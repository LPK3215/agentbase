## 1.1 四问（是否真需要 Agent）

| 问 | 判定 | 依据 |
|---|---|---|
| 1.1.1 是否是（终端）Agent 产品 | **不过** | 项目自定位是「AI Agent **后端脚手架**」：克隆仓库 → 改 YAML → 启动 → 二次开发。不是面向终端用户的 Agent 应用，也不是模板生成 CLI（`docs/提示词.md` §2、`docs/project-positioning.md`）。 |
| 1.1.2 是否有单一业务任务闭环 | **不过** | 无「订票 / 客服 / 研报」一类固定业务闭环。提供的是 invoke / stream / resume / eval 的**机制闭环**。 |
| 1.1.3 是否有安全边界 | **部分** | 有 workspace 路径约束、`.env`/`*.key` path deny、`interrupt_on`、code_execute 子进程、db_query SELECT-only。无 `SECURITY.md`、无书面红线表、默发 Agent `interrupt_on: {}`。 |
| 1.1.4 是否有交付价值 | **有** | 30 个 registry、48 工具、9 中间件、CLI 21 条、FastAPI ~144 路由、零配置 SQLite。二次开发少造轮子。 |

**出口处置**：应用型建议 Demo 终止。**用户要求继续，按脚手架型口径检查。** 本句为定档铁记，后续章节不得改回应用型「必须默认开」口径。

## 1.3 技术栈（五控制面）

| 控制面 | 现状 |

## 1.4 目标、边界、非目标

**服务对象**：二次开发者（用本仓组装自己的 Agent 后端），不是终端用户。

**交付物**：YAML 配置 + Python 扩展点（registry / factory）+ CLI/API 运行时。

**非目标**（`docs/提示词.md` §2 禁止项，A.1.5 圈外）：

- 模板生成（`init` / `create` / `scaffold` 命令）
- 前端 UI
- SaaS 托管
- 与 Agent 后端无关的 CRUD 堆砌

**最长运行时间（1.4.3）**：有。`runtime.recursion_limit` 默认 50、硬顶 200；`model.timeout_seconds` 默认 120；timeout 中间件；code_execute / db_query 自带 timeout。

**拒绝场景（1.4.4）**：产品级「What It Is Not」有文档。Agent 级拒绝策略（拒答库 / 禁操作清单）无独立书面件，转入 7.5.1 缺件。
