## 7.1 身份、权限、凭证

| 点 | 查什么 | 判定 | 证据 | 缺件 |
|---|---|---|---|---|
| 7.1.1 权限上界 | 模型动作是否被权限封顶 | **警示** | `PermissionRule` allow/deny/interrupt；默发 deny `.env`/`*.key`/`*.pem`/`secrets/**`，allow `workspace/**` 读写。API：`AGENTBASE_API_KEY` 未设则 `_is_auth_enabled()` 为假，`_verify_auth` 直接 True（**fail-open**）。JWT 若 `type=jwt` 且 secret 空则 **fail-fast** 拒启动 | 未做「越权写 / 读密钥」实测（E4）。Agent 工具权与请求者权未强制对齐。生产必须设 API key 或 JWT |
| 7.1.2 身份 | 谁在跑 | **警示** | `thread_id` / `request_id`；`user_id` 仅 metadata 可选；JWT `sub` | 未证明模型不可伪造 user_id（E4） |
| 7.1.3 读写分离 | 读工具 vs 写工具 | **警示** | 规则支持 operations 分列；默发同一 agent 同时有 read_file 与 write_file/kb_delete/skill_delete | 默发未拆「只读画像」 |
| 7.1.4 临时凭证 | 密钥生命周期 | **警示** | `secrets` 模块默认关；模型 key 走 env；apikey_manager 默认可选 | 无短时凭证默认实现 |
| 7.1.5 三分类书面化 | 允许 / 需批 / 禁止 | **警示** | interrupt_demo 把 write_file 列为需批；默发无分类表；path deny 近似「禁止」 | 无全工具风险分级表 |
| 7.1.6 回收 | 撤权/撤钥 | **达标（机制，默认关）** | apikey revoke；RBAC unassign | 默认关 |
| 7.1.7 服务端注入身份 | 身份是否仅服务端 | **警示** | 无 `tenant_id`。invoke metadata 可带 user 字段，未见强制覆盖为网关身份 | 多租户不可直接用 |

## 7.5 红线、攻击回归、红队

### 7.5.1 红线清单书面化（fail-closed）— 本档门槛

**判定：不达标。**

仓库内检索：无 `SECURITY.md`、无 `docs/security.md`、无「安全红线清单（fail-closed）」表。`.gitignore` 敏感文件规则与 system_prompt「Do not invent unavailable tools」**不等于** 7.5.1。

G1 + 脚手架：**7.5.1 是唯一硬门槛**。模板存在即达标。当前连模板都没有。

**补件路径（强制）：附录 B.1** — 在 `SECURITY.md` 或 `docs/security.md` 放入 fail-closed 表（R1 越权 / R2 危险无确认 / R3 审计缺失 / R4 跨租户 / R5 凭据暴露 / R6 不可逆无确认），并声明「脚手架由使用者按场景启用」。

**与 10.1.2「红线被平均掩盖」的区分**：本项是「**没有清单**」，不是「有清单但用总分翻盘」。检查者未把 7.5.1 混进平均分（见 10 / A.2.4）。因此 **block 不成立**，但本章不能判达标，结论档封顶原型-A。
