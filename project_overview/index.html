📋 项目简介

AgentBase 是一个生产级 AI Agent 框架 / LLM Agent 脚手架，基于 deepagents、LangChain 和 LangGraph 构建。通过 YAML 配置组装和运行生产级 AI Agent，无需编写样板代码。提供 30 个可插拔扩展注册器、21 命令 CLI、FastAPI 服务层（145 个 REST/WebSocket 路由），覆盖 AI Agent 后端所需的所有基础设施：模型配置、提示词模板、用户管理、API Key 管理、会话管理、记忆管理、RAG 知识库、文档解析、任务队列、API 安全、追踪和评估。

🚀 快速开始

安装

Bash
pip install agentbase

# 或从源码
git clone https://github.com/LPK3215/agentbase.git
cd agentbase
uv sync

初始化与运行

Bash
# 复制配置
cp .env.example .env

# 验证配置
agentbase doctor

# 启动 API 服务
agentbase serve --reload

# 或 Docker 启动
docker compose up -d

API 文档：http://localhost:8000/docs

CLI 命令

Bash
agentbase serve      # 启动 API 服务
agentbase agent run   # 运行 Agent
agentbase doctor      # 配置检查
agentbase migrate     # 数据库迁移
agentbase --help      # 查看全部 21 个命令
